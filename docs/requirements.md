## 1. 项目概述

### 1.1 背景
用户需要一个轻量级的静态网站托管平台，允许管理员上传 ZIP 格式的静态网站压缩包，并通过独立的公网端口对外提供服务。

### 1.2 目标用户
- **管理员**：使用管理后台（端口 3001）上传和管理网站
- **最终用户**：通过公开端口（端口 3000）访问托管的网站

### 1.3 核心约束
- 双端口架构：管理端口与公共端口物理隔离
- 单一管理员账号，密码通过邮箱找回
- 界面美观、操作便捷、功能齐全

## 6. API 设计

### 6.1 管理 API (端口 3001)

#### 认证相关
```
POST /api/login              管理员登录
POST /api/logout             管理员登出
POST /api/forgot-password    请求密码重置邮件
POST /api/reset-password     重置密码
```

#### 网站管理
```
GET    /api/sites             获取网站列表
POST   /api/sites             上传新网站
GET    /api/sites/:slug       获取网站详情
PUT    /api/sites/:slug       更新网站信息
DELETE /api/sites/:slug       删除网站
```

### 6.2 公开 API (端口 3000)

```
GET /sites/:slug/*           提供网站文件
GET /                        重定向到站点列表或默认站点
```

## 9. 部署与配置

### 9.1 环境变量
```env
# 必填
ADMIN_USER=admin
ADMIN_PASSWORD=admin123
SESSION_SECRET=random-secret-key

# 可选 - 邮件配置
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your@email.com
SMTP_PASS=your-password
SMTP_FROM=noreply@example.com

# 可选 - 端口配置
ADMIN_PORT=3001
PUBLIC_PORT=3000
```

### 9.2 快速启动
```bash
# 1. 安装依赖
npm install

# 2. 启动服务
npm start

# 3. 访问
# 管理后台: http://localhost:3001
# 公共端口: http://localhost:3000
```
